# Admin Page Pattern

The GoldenCell Admin Page Pattern defines the standard structure for every administrative page.

Every page should look familiar.

Users should never need to learn a new layout.

Business workflows should always follow the same visual structure.

---

# Golden Rule

One Pattern.

Many Pages.

Users learn the pattern once.

Then work everywhere.

---

# 1. Purpose

The purpose of the page pattern is

- reduce learning time
- improve productivity
- increase predictability
- maximize consistency

The page pattern is more important than page design.

---

# 2. Standard Page Hierarchy

Every page follows the same hierarchy.

```
Breadcrumb

↓

Page Title

↓

Search / Filter

↓

Toolbar

↓

Primary Content

↓

Pagination

↓

Optional Detail

↓

Optional Action Area
```

Never change this hierarchy without strong business reasons.

---

# 3. Page Header

Contains

- Breadcrumb
- Title
- Description (Optional)

The page title should immediately explain

"What is this page?"

---

# 4. Search Area

Search appears at the top.

Search is always visible.

Advanced Search may collapse.

Frequently used conditions remain visible.

Search should never interrupt workflow.

---

# 5. Toolbar

Toolbar appears immediately above the primary content.

Contains

- Create
- Export
- Delete
- Refresh
- Additional Actions

Primary Action remains on the right.

Secondary actions remain on the left.

---

# 6. Primary Content

Primary Content is usually

- Table
- List
- Dashboard Widget

The primary content occupies the largest visual area.

Information always has priority.

---

# 7. Table Pattern

Tables are the primary business component.

Tables support

- Sorting
- Filtering
- Pagination
- Bulk Selection
- Bulk Actions

Horizontal scrolling should be minimized.

---

# 8. Detail Pattern

Details should open using

Priority

1. Drawer

2. New Page

3. Modal

Use Modals only for small tasks.

Large business workflows should not use Modals.

---

# 9. Form Pattern

Forms follow a consistent structure.

Labels align consistently.

Validation appears immediately.

Primary Action

Save

Always appears in a predictable position.

---

# 10. Empty States

Every page defines

Empty

Loading

Error

Permission Denied

No Results

These states are mandatory.

---

# 11. Pagination

Pagination always appears below primary content.

Never above.

Users expect it below the data.

---

# 12. Responsive Strategy

Desktop

Primary experience.

Tablet

Reduced spacing.

Mobile

Simplified workflow only.

Business productivity remains the priority.

---

# 13. Page Consistency

Users should always know

Where am I?

What am I viewing?

What can I do next?

Consistency reduces thinking.

---

# 14. Business Priority

Every page should support

Business

↓

Workflow

↓

Information

↓

Actions

↓

Visual Design

Never reverse this order.

---

# 15. Page Manifesto

Pages exist to complete work.

Search before Action.

Action before Detail.

Information before Decoration.

Consistency before Creativity.

Build Pages users never have to relearn.
